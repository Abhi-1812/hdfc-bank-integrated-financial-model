# HDFC Bank — Integrated Financial Modeling & Equity Research


## Project Overview

This project presents an integrated financial modeling and equity research analysis of **HDFC Bank Limited**, designed to evaluate the bank from both an operating and investment perspective.

The project combines historical financial analysis, banking-specific operating drivers, forward financial forecasting, valuation, downside stress testing, M&A analysis, capital-raising scenarios, risk analysis and investment-committee style reporting.

The analysis connects historical performance with forward-looking assumptions to evaluate the impact of loan growth, deposit growth, Net Interest Margin (NIM), profitability, capital requirements and strategic initiatives on the bank's future financial profile.

---

## Objectives

The main objectives of the project were to:

- Analyze HDFC Bank's historical financial performance.
- Identify the key operating drivers of a banking business.
- Build a forward-looking financial forecast through FY30.
- Estimate intrinsic value using banking-appropriate valuation methodologies.
- Test valuation under different profitability and required-return assumptions.
- Stress-test the impact of NIM compression on earnings and capital.
- Evaluate potential M&A transaction economics.
- Compare alternative capital-raising structures.
- Convert the analysis into an investment-research and investment-committee format.

## Valuation Framework

The project uses banking-oriented valuation approaches rather than relying exclusively on a conventional DCF.

### Price-to-Book Valuation

The model estimates:

**Forecast Book Value Per Share × Target P/B Multiple = Implied Share Price**

The justified P/B framework incorporates profitability and required return assumptions.

### Residual Income Valuation

Residual income is calculated as:

**Residual Income = Net Income − Equity Charge**

where:

**Equity Charge = Opening Book Value × Cost of Equity**

Future residual income and terminal value are discounted to estimate intrinsic equity value.

## Risk & Stress Testing

A dedicated downside scenario evaluates the effect of a **50 bps NIM compression**.

The stress test flows the impact through:

**NIM ↓  
→ Net Interest Income ↓  
→ Net Income ↓  
→ ROE ↓  
→ Intrinsic Value ↓**

The analysis also evaluates the effect on:

- Equity
- Risk-weighted assets
- CET1
- Capital buffer
- Earnings resilience

This was designed to identify the model's key earnings and valuation sensitivities.
